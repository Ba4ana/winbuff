# winbuff

Набор административных утилит для подготовки и обслуживания Windows- и Debian-систем.

**Текущая версия Windows-загрузчиков:** `0.6.5`  
**Версия 7-Zip:** `26.03` (`2603`)

> [!WARNING]
> Скрипты выполняют системные изменения с повышенными правами. Перед эксплуатацией проверяйте исходники и тестируйте изменения на отдельной системе.

## Состав репозитория

| Файл | Назначение |
|---|---|
| `winbuff.py` | Windows-загрузчик на Python: подготавливает рабочие каталоги, устанавливает 7-Zip, получает внешний архив и запускает дальнейшую установку. |
| `_winbuff.ps1` | Windows-загрузчик для Windows PowerShell с аналогичным назначением и дополнительной настройкой Windows. |
| `winbuff.sh` | Интерактивная утилита для первичной настройки и обслуживания Debian. |
| `cheklist.md` | Исторический чек-лист Linux-настройки. Частично расходится с текущим `winbuff.sh`. |
| `license.md` | Лицензия MIT. |
| `readme.md` | Документация проекта. |

## Windows

Оба Windows-загрузчика сейчас используют версию `0.6.5` и 7-Zip `26.03`.

Основной сценарий:

1. подготовка рабочих каталогов;
2. проверка установленной версии 7-Zip;
3. установка 7-Zip при необходимости;
4. получение и распаковка внешнего архива;
5. копирование дополнительных компонентов;
6. настройка автозапуска;
7. запуск следующей части установки.

`winbuff.py` требует Python 3 и пакет `requests`. `_winbuff.ps1` рассчитан на Windows PowerShell.

Оба загрузчика используют общий рабочий каталог и общую задачу планировщика, поэтому одновременно запускать их не следует.

Внешний архив не хранится в этом репозитории. Из-за этого полное итоговое поведение Windows-установки нельзя проверить только по исходникам `winbuff`.

### Различия загрузчиков

| Возможность | `winbuff.py` | `_winbuff.ps1` |
|---|---:|---:|
| Версия | `0.6.5` | `0.6.5` |
| 7-Zip | `26.03` | `26.03` |
| Проверка интернет-соединения | TCP | ICMP |
| Распаковка ZIP | Python `zipfile` | PowerShell с резервным способом распаковки |
| Дополнительная настройка Windows Firewall | Нет | Да |
| Изменение настроек запуска PowerShell-скриптов | Да | Да |

## Linux / Debian

`winbuff.sh` запускается от `root` и предоставляет интерактивное меню.

| Пункт | Действие |
|---:|---|
| `1` | Первичная настройка системы и установка базовых пакетов. |
| `2` | Обновление пакетов. |
| `3` | Настройка автоматических обновлений. |
| `4` | Удаление автоматических обновлений. |
| `5` | Установка Zabbix Agent для поддерживаемых версий Debian. |
| `6` | Настройка сетевого интерфейса. |
| `7` | Обновление Debian 12 до Debian 13 с резервным копированием APT-конфигурации. |
| `8` | Создание или повторная настройка пользователя `tech`. |
| `9` | Настройка удалённого доступа root. |
| `10` | Очистка истории текущего shell-сеанса. |

### Повторный запуск пункта `8`

Пункт создания пользователя `tech` проверяет, существует ли пользователь. Если пользователь уже есть, повторное создание не выполняется. Скрипт повторно проверяет необходимые компоненты и применяет требуемую конфигурацию.

Если пользователя ещё нет, используется стандартное интерактивное создание пользователя.

### Обновление Debian 12 -> 13

Перед major-upgrade скрипт обновляет текущую систему и сохраняет резервную копию основной APT-конфигурации. Сторонние репозитории необходимо проверять отдельно перед использованием на production-системе.

### Проверка синтаксиса

```bash
bash -n winbuff.sh
```

## `cheklist.md`

`cheklist.md` является историческим документом и не полностью соответствует текущему `winbuff.sh`. В частности, часть перечисленных там настроек отсутствует в текущем скрипте, а некоторые пакеты и параметры изменились.

Для фактического поведения Linux-части источником истины является `winbuff.sh`.

## Известные ограничения

- часть конфигурации Windows-загрузчиков задана непосредственно в исходном коде;
- часть Windows-сценария находится во внешнем архиве и отсутствует в репозитории;
- перед запуском внешнего архива нет встроенной проверки цифровой подписи;
- приветственный текст Windows-загрузчиков упоминает точку восстановления, но в доступных исходниках её создание не реализовано;
- часть ошибок не останавливает дальнейшее выполнение;
- операции изменения сети, удалённого доступа и major-upgrade Debian требуют отдельной проверки перед production-применением.

## Рекомендации

- вынести изменяемую конфигурацию из исходного кода;
- использовать защищённый канал доставки внешнего архива;
- добавить проверку целостности или цифровой подписи внешних файлов;
- останавливать выполнение после критических ошибок загрузки и распаковки;
- синхронизировать `cheklist.md` с текущим `winbuff.sh` либо удалить его как устаревший;
- добавить автоматические проверки синтаксиса Python, PowerShell и Bash.
